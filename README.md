# Burger House

Burger House is a responsive website for an imaginary burger business,
created as a front-end group assignment.

## Project Purpose

The website introduces the business and allows visitors to explore
burgers, view prices, learn about the business, and find its contact
information.

## Website Pages

- Home: Introduces Burger House and highlights popular burgers.
- Menu: Displays burgers with images, descriptions and prices.
- About: Explains the business's story and values.
- Contact: Displays contact details and a demonstration contact form.

## Technologies Used

The website is built with HTML and CSS. It uses semantic HTML,
Flexbox, media queries, responsive images, and the Roboto font.

The pages share an external stylesheet, navigation, and footer.
The mobile navigation uses a CSS-only hamburger menu.

No JavaScript is used.

## How to Run the Website

Download the project as a ZIP file and extract it.

Open index.html in a web browser, then use the navigation links
to visit the other pages.

Keep the HTML files, style.css, and the images folder together.
You need an internet connection to load Google Fonts.

## Project Limitations

This is a front-end demonstration, not a complete online ordering
system.

The order links take visitors to the Contact page. There is no
shopping cart or payment system, and the demonstration contact
form does not send messages.

## Development

The project was developed collaboratively through GitHub, with
